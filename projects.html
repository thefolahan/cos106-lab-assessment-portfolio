Personal Projects

Currently In Progress.

  • 842Games

    Building

    A realtime multiplayer game server for one shared screen and many phones. Rooms live in memory behind WebSockets, and every game is a pure reducer that renders a public view for the television and a private one for each phone. Physics shots are simulated on the server and streamed as frames, so no player can fake a result.

    • TypeScript
    Private repository on GitHub

  • OyaTrade

    Building

    A prediction market for Africa, launching in Nigeria, designed around a central limit order book. Every kobo moves through a double entry ledger whose rules live in Postgres itself, so an unbalanced transaction is rejected before it can be saved. The client ships in eighteen languages.

    • Go
    • TypeScript
    • SQL
    Private repository on GitHub

  • playstation-script

    Building

    A PS5 automation engine over the Remote Play protocol. It opens an authenticated session, sends controller input, decodes the video stream into frames, and runs macros whose every step is checked with computer vision, so a script reacts to what is on screen instead of pressing blindly.

    • Python
    Private repository on GitHub
